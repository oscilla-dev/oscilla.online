# Oscilla

**OpenSCENARIO DSL (OpenSCENARIO 2) in the browser — write, validate, preview.**

[Open Editor](https://osc2studio.online/app/) · [Website](https://osc2studio.online) · [Docs](https://docs.osc2studio.online)

![Oscilla: OpenSCENARIO DSL editor with live 3D scene preview](./image.png)

Oscilla is a web-based IDE for OpenSCENARIO DSL. It pairs a professional editor with
real-time syntax and semantic validation, intelligent code completion, a live 3D scene
preview and OpenDRIVE map exploration — all in the browser, with nothing to install.

## Features

- **Professional editor** — syntax highlighting, completion, bracket matching, code folding.
- **Real-time validation** — syntax and semantic errors as you type, against the official
  OpenSCENARIO 2 standard, powered by a C++ core compiled to WebAssembly.
- **3D scene preview** — watch vehicles, roads and event sequences run without leaving the editor.
- **OpenDRIVE map preview** — import `.xodr` road networks and explore layouts in 3D.
- **Zero installation** — the whole toolchain runs in the browser.

## Quick start

1. **Open** [osc2studio.online/app](https://osc2studio.online/app/) — no installation.
2. **Sign in or continue as a guest.** Guests can edit and validate; the 3D preview needs an account.
3. **Write** a scenario — completion and validation run as you type.
4. **Preview** scenes and maps, then **download** your `.osc` files for simulation.
